================  FONT GIỐNG TEMPLATE 3  ================

Template 3 (cinelove) dùng 7 font sau:

MIỄN PHÍ (web đã tự tải qua Google Fonts, không cần làm gì):
  • Playfair Display   — chữ Việt / tiêu đề
  • Sacramento         — script (thay cho các font calligraphy nếu chưa có)

THƯƠNG MẠI (phải tải/mua rồi bỏ vào thư mục public/fonts/ này):
  • Faugllin Balseyn   -> đặt tên file: FaugllinBalseyn.ttf  (hoặc .otf / .woff2)
  • Katty Diona        -> đặt tên file: KattyDiona.ttf
  • The Hamstter       -> đặt tên file: TheHamstter.ttf
  • Signora            (tuỳ chọn, template 3 có dùng)
  • Mallong            (tuỳ chọn, template 3 có dùng)

Tìm mua/tải các font thương mại tại: creativemarket.com, elements.envato.com,
fontspace.com, dafont.com (kiểm tra bản quyền trước khi dùng).

CÁCH DÙNG:
  1) Tải file font (định dạng .ttf, .otf hoặc .woff2).
  2) Đổi tên đúng như trên và chép vào thư mục public/fonts/.
  3) Tải lại trang — web sẽ tự dùng font đó.
  Nếu chưa bỏ font vào, web vẫn đẹp với Sacramento + Playfair (miễn phí).

Muốn đổi font nào dùng ở đâu: sửa biến --font-name / --font-script / --font-hand
trong file app/globals.css.

------------------------------------------------
TÊN DÂU/RỂ (font "Classico Mini" - tuỳ chọn):
  Classico Mini là font thương mại (không có trên Google Fonts).
  Nếu bạn có file, đặt tên: ClassicoMini.ttf (hoặc .otf / .woff2) và bỏ vào thư mục này.
  Chưa có -> web tự dùng Cormorant Garamond (miễn phí, đủ dấu tiếng Việt).
  Lưu ý: kiểm tra font Classico Mini có hỗ trợ tiếng Việt (dấu) trước khi dùng cho tên có dấu.
